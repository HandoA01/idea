# 아이디어: 대학생 수면 유도 에이전트

> 상태: 아이디어 구체화 중 | 타겟: 잠 못 드는 대학생
> 최초 작성: 2026-11-19

---

## 핵심 서사 (마케팅 훅)

> "잠자리에 누웠는데 폰 보고 있잖아 → 그 폰으로 걱정 털어놔 → 에이전트가 뇌 꺼주는 대화 이어감 → 모르게 잠듦"

- 기존 수면 앱은 "콘텐츠 소비" 모델 (듣기만 함) → 개인 상태 반영 없음
- 대학생이 잠 못 드는 진짜 이유 = **폰 + 불안/걱정** → 대화형 개입이 맞는 형태
- 금지나 차단이 아니라, 이미 폰 잡은 행동에 올라탐

---

## 문제 검증 — 20대 실제로 잠 못 자나?

**한국 20대 데이터:**
- 수면 방해 1위: **휴대폰 사용** (45.9%) + **심리적 스트레스** (45.5%) — 대학내일20대연구소
- 충분히 잔 것 같아도 피곤함: 56.5% (수면 장애 증상 중 1위)
- 부정적 감정 경험 비율 (스트레스, 불안, 외로움) 전 연령대 중 20대가 최고
- 수면장애 환자 2025년 94만 4천 명, 2018년 대비 63% 증가 (건강보험공단)

**글로벌 대학생 데이터:**
- 전 세계 대학생 96,000명 대상 연구(2025): **46.9%**가 불면증 증상
- 74.3%가 수면 질 낮은 "poor sleeper" (미국대학건강협회 2025)
- 대학생 불면증 비율 18.5% vs 비학생 7.4% → **2.5배 높음**
- 외로운 대학생은 그렇지 않은 학생 대비 불면증 2배
- 수면 문제 1일 추가 경험 시 → 수업 포기 가능성 10% 상승

**결론: 문제 실재함.** 특히 "폰 + 불안"이 핵심 트리거 → 에이전트 개입 접점이 명확.

---

## 왜 기존 앱이 안 되나

| 솔루션 | 한계 |
|--------|------|
| Calm / Headspace | 콘텐츠 재생 → 수동적 소비, 오늘 나의 상태 반영 없음 |
| ChatGPT / 일반 LLM | 질문-답변 구조 → 뇌 각성시킴, 수면 목적 설계 아님 |
| White noise 앱 | 불안/걱정 해소 없음 |
| 수면 추적 (오라링 등) | 기록만, 개입 없음 |

> **공통 빈틈:** "지금 잠 못 자는 이유"를 대화로 풀어주면서 뇌를 단계적으로 꺼주는 에이전트가 없음

## 에이전트 작동 방식 (가설)

```
밤 11시~새벽 2시, 폰 집어듦
    ↓
앱 or 카톡채널 열기 "잠 안 와?"
    ↓
에이전트가 오늘 걱정/생각 덤핑 유도
  ("오늘 뭐가 머릿속에 맴돌아?")
    ↓
걱정 목록화 → "지금 당장 해결 안 해도 됨" 프레이밍
    ↓
대화 톤이 점점 단조로워짐 + 응답 속도 느려짐
  → 뇌 각성 단계적으로 낮춤
    ↓
4-7-8 호흡 or 바디스캔 가이드 (짧게, 텍스트로)
    ↓
"폰 내려놓고 눈 감아, 내일 보자" 종료
```

**핵심 설계 원칙:**
- 대화가 길어질수록 에이전트 응답이 짧고 느려짐 (각성 낮추기)
- 문제 해결 대화 X → 감정 덤핑 + 프레이밍 대화
- CBT-I(불면증 인지행동치료) 원리 접목: 걱정 시간 분리, 수면 압박 제거
- 음성 모드: 낮고 단조로운 TTS

## 타겟 세분화

| 세그먼트 | 증상 | 접근 |
|----------|------|------|
| 불안형 | 과제/취업/인간관계 걱정으로 잠 못 잠 | 걱정 덤핑 → 프레이밍 |
| 폰 중독형 | 릴스/틱톡 보다 새벽 됨 | "이 앱만 켜" 진입점 |
| 외로움형 | 혼자 있는 감각이 불편 | 심야 대화 상대 역할 |

## 비즈니스 모델 가설

- **B2C 구독**: 월 4,900~7,900원 (Calm 한국 가격대 하회)
- **B2B**: 대학 학생처 / 기숙사 멘탈헬스 케어 프로그램 납품
- 수면 개선 효과 측정 가능 → 리텐션 명분 있음
