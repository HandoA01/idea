# 아이디어: 저장한 콘텐츠 → 실행 가능한 스킬 가이드

> 상태: 아이디어 단계 (타겟층 미확정)
> 최초 작성: 2026-11-19

---

## 원초적 pain point

인스타그램에 Claude 플러그인 추천 릴스 같은 유용한 콘텐츠가 계속 뜸.
저장은 하는데 실제로 써본 적은 없음. 계속 미뤄짐.

→ **"저장 = 실행 의도" 인데 실행으로 연결되지 않는 콘텐츠 묘지** 현상

---

## 아이디어 개요

스크린샷, 저장된 릴스, 북마크 등을 가져와서  
AI가 카테고리별 **실행 가능한 스킬 가이드**로 정리해줌

예시:
- 저장된 릴스 10개 (Claude 플러그인 관련) → "Claude 활용 가이드 / 작업별 플러그인 추천" 문서로 정리
- 스크린샷 더미 → 주제별 클러스터링 + 요약 + 실행 체크리스트

---

## 문제점 / 열린 질문

### 타겟 문제 (가장 큰 약점)
- 이 pain point를 가진 사람: 정보 과잉에 시달리는 **직장인 / 개발자 / 콘텐츠 소비 많은 사람**
- 대학생이 메인 타겟이 되기 어려움 — 저장 콘텐츠 양이 적고, 절박한 니즈가 약함
- **대학생으로 연결하려면** 별도의 각도가 필요 (예: 전공 공부 자료 정리, 취업 준비 콘텐츠 큐레이션)

### 경쟁 각도 문제
- Readwise: 하이라이트/저장 콘텐츠 복습 자동화
- Notion AI: 붙여넣으면 정리해줌
- 차별점이 "릴스/스크린샷 처리"에 있다면 — 기술적으로 가능한가?
  - 인스타 저장 릴스: API 없음, 수동 공유만 가능
  - 스크린샷: OCR + AI 처리는 가능

### 수익화 문제
- 얼마에 팔 수 있는가? 월 얼마면 쓰겠는가?
- 직장인 대상이면 B2B SaaS 쪽이 더 현실적일 수도

## 살릴 수 있는 각도 (브레인스토밍)

- **대학생 버전으로 좁힌다면:** "전공 유튜브/강의 영상 저장해뒀는데 복습 못 하는" 패턴에 집중 → 강의 영상 → 요약 + 플래시카드
- **직장인 버전:** 슬랙 북마크 / 노션 클리핑 → 주간 액션 아이템 정리
- **니치 버전:** Claude / AI 도구 튜토리얼 전문 큐레이션 앱
