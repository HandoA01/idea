# 아이디어: 구매 후기 → 블로그 + 숏폼 자동화 (쿠팡 파트너스 수익화)

> 상태: 아이디어 구체화 중 | 타겟: 부업 원하는 대학생
> 최초 작성: 2026-11-19

---

## 핵심 서사 (마케팅 훅)

> "어차피 뭔가 사잖아 → 짧게 후기만 남겨 → 블로그랑 숏폼 알아서 올라가고 → 쿠팡 파트너스로 돈 들어옴"

- 블로그가 없어도 됨 — **구매 행동 자체가 콘텐츠 소스**
- 대학생이 이미 하는 행동(쇼핑)에 올라타는 구조
- 긴 글 쓰라는 게 아니라 알림에 세 줄 → 마찰 최소화

---

## 사용자 플로우

```
쿠팡 구매 (or 스크린샷/이메일)
    ↓
앱이 감지 → "○○ 사용해보셨나요? 한마디만 남겨주세요" 알림
    ↓
사용자가 짧게 입력 (3줄 이내, 카톡 답하듯)
    ↓
AI가 후기들 누적 → 블로그 글 자동 생성 + 쿠팡 파트너스 링크 삽입
    ↓
유튜브 숏폼 / 인스타 릴스 자동 생성 + 업로드
    ↓
조회수 → 클릭 → 파트너스 수수료 수익
```

---

## 시장 맥락 (왜 지금인가)

- 네이버 **제로클릭 비율 56% → 69%** (2024.5 → 2025.5): 블로그 써도 클릭이 안 붙는 시대
- AI 브리핑이 20% 쿼리에 직접 답변 → 블로그 유입 구조적 감소
- 한국 AI 사용자 60%가 "검색의 절반 이상을 AI로 대체" (2025 정부 조사)
- → 블로그 SEO 전략이 흔들리는 시점에 숏폼이 대안 채널로 부상

---

## 기술 허들

구매 이력을 어떻게 가져오느냐가 핵심 난관.

| 방법 | 가능 여부 | 비고 |
|------|-----------|------|
| 쿠팡 소비자 API | ❌ 공개 API 없음 | 불가 |
| 구매 완료 스크린샷 → OCR | ✅ 가능 | 수동 업로드 1회 필요 |
| 주문 확인 이메일 파싱 | ✅ 가능 | Gmail/네이버메일 연동 |
| 앱 내 "공유하기"로 링크 전달 | ✅ 가능 | 가장 낮은 마찰 |

**MVP 추천:** 이메일 파싱 or 스크린샷 첨부 중 하나로 시작
알림 채널 MVP: 카카오채널 or 슬랙봇 (앱 개발 전)

---

## 기존 경쟁 서비스

- **Pictory / Fliki / Vidpal** — 블로그 URL → 영상 변환. 근데 한국어 약하고, 구매 후기 플로우 없음
- **쿠팡 파트너스 자체** — 링크 생성만, 콘텐츠 자동화 없음
- **리뷰 앱들 (Trustpilot 등)** — 리뷰 수집만, 콘텐츠 생성 없음

> **차별점:** "구매 감지 → 마이크로 후기 → 멀티채널 자동 발행 → 파트너스 수익화"를 하나의 루프로 묶은 서비스는 없음
